## What It Is

A lightweight first-ever hackathon run by the Portaldot team on DoraHacks. Low-barrier format: build a prototype, submit GitHub + demo video. Open globally. No team size cap stated.

**Chain:** Portaldot — Substrate-based, POT native token, 14 decimals, SS58 format 42  
**Mainnet WSS:** `wss://mainnet.portaldot.io`  
**Explorer:** https://www.portaldot.io (has "Local Node" option)  
**SDK:** `pip install substrate-interface` (standard py-substrate-interface)
